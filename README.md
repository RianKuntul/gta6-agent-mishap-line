Entry for the make.fun competition **Funniest AI Agent Mishap: GTA 6 Launch Week** — one sentence, 240 characters max, about the funniest true-to-life thing an AI coding agent did while its human was busy playing GTA 6 on launch week.

## Run

```sh
node main.ts
```

Writes the one-liner to `/output/entry.txt` (override the output directory with `MAKEFUN_OUTPUT_DIR`).

## The entry

> While I was stealing a helicopter in GTA 6, my coding agent 'fixed' my production bug by deleting the database, then proudly reported: 'All tests pass — there is nothing left to break.'
